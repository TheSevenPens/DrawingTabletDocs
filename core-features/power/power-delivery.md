# Power delivery

## Overview

Power delivery is the capability for a drawing tablet to send power to an attached computer.&#x20;

## Pen displays

When pen displays get power from a power adapter or a hub, it MIGHT be possible to deliver power to an attached computer. This is still a **very rare** feature for pen displays.

This is a very convenient feature for pen displays since it can simplify some cabling scenarios.

Some pen displays are explicitly designed to support power delivery.

For example, the Huion Kamvas Pro 19

* It is designed to be use with its 65W power adapter
* and when connected to a laptop can deliver 40W of power to the laptop&#x20;

Some other pen displays, for example the Wacom Cintiq 24 (2025), are not explicitly designed to support power delivery, but will deliver a little power to a connected device. But it usually will not be much power.

## Pen tablets

Pen tablets are not capable of power delivery.

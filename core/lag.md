# Brush lag

## Introduction

Brush lag is the lag caused by how long it takes to render a stroke or paint action. It has nothing to do with the drawing tablet hardware or driver.

{% hint style="info" %}
For lag related to the tablet and driver, see [Pointer lag](pointer-lag.md).
{% endhint %}

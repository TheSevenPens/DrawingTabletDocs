# Magnet field detection

## Overview

For some devices — especially standalone drawing tablets — it is useful to check where magnets are located. For this purpose, I use a magnetic field viewing film.

For more information about how these films work, see [Magnetic field viewing film](https://en.wikipedia.org/wiki/Magnetic_field_viewing_film).

## My equipment

The one I use is a 4" × 4" square film. When pressed against a device's surface, it reveals magnetic fields. It costs about $18 USD on Amazon.

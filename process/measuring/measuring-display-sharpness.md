# Measuring display sharpness

## Overview

Pen displays have some anti-glare treatment that introduces a small amount of blur. It can vary widely between pen displays. I've created a simple test image so I can consistently evaluate the blur.

## Tester

This is a basic tester build with Claude: [https://github.com/TheSevenPens/PixelSharpnessTester](https://github.com/TheSevenPens/PixelSharpnessTester) \
\
Essentially it takes exclusive access of a display and shows test patterns (you can choose which ones) to help you see the sharpness. The images it draws as NOT anti-aliased to better let you see the sharpness.&#x20;

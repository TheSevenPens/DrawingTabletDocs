# Recommended drawing tablets for whiteboarding

## Scenario

When I "whiteboarding" i include any scenario where you are drawing something for the sake of communicating visually.&#x20;

Example:

* Online teaching
* Zoom call
* Recording Khan-Academy style videos

## Good news

You don't need a fancy tablet for white boarding

* For pen tablets (screenless tablets) - Any medium size beginner pen tablet will work. See:  See: [Beginner pen tablets](recommended-drawing-tablets-for-beginners/beginner-pen-tablets.md)
* For pen displays (screen tablets) -  [Beginner pen displays](recommended-drawing-tablets-for-beginners/beginner-pen-displays.md)

## Pen tablet vs Pen display

Both work, but if you are drawing things for these scenarios, I do encourage you to look into a pen display (screen tablet)

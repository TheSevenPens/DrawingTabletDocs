# Standalone drawing tablet recommendations

## Overview

A standalone drawing tablet is ideal if you need to draw away from home or away from your desk. People look for standalone tablets because:

* They can travel with it
* They can be used on the couch, in the bed, on a bus etc.
* Doesn't require the connection to a computer. (Because it is a computer)

# ASUS ProArt Pen (MPA01) notes

## Overview

This is a basic UD-EMR pen with a few interesting features

## Basics

* Product page: [ASUS ProArt Pen (MPA01).](https://www.asus.com/us/displays-desktops/accessories/proart-accessories/proart-pen-mpa01/)
* Pen tech: EMR (UD EMR)
* Buttons: 1
* Eraser: YES
* Tilt: YES
* Comes with: Pen is included with the Asus ProArt Display PA169CDV pen display.&#x20;

## Surprising features for a UD EMR pen

* **This pen supports tilt.** This is highly unusual for an UD EMR pen. However, keep in mind that EMR tech inherently supports tilt. So what it means is that the tablet it comes with - the ASUS ProArt PA169CDV - simply does not prevent tilt from working whereas other UD EMR tablets do artificially prevent tilt from working.
* **This pen has an eraser.** Another thing that is super-rare for UD EMR pens. Unlike tilt. the pen itself must have speciall hardware to support an erase.

# Ergotron monitor arms

## Overview

I tend to use Ergotron arms for my monitors and pen displays.

* Ergotron HX - I have 4 of these arms.
* Ergotron LX - I have 1 of these arms.

## Ergotron HX

For pen displays `>=24"`, I use the **Ergotron HX**. This is a very well-designed and rugged arm. I use it with:

* Wacom Cintiq Pro 27
* Huion Kamvas 24 Pro 4K
* Many 32" monitors

## Ergotron LX

For `~22"` pen displays, I use the Ergotron LX. It is not as rugged as the Ergotron HX, but it has been reliable and has a good range of motion.

## Wobble

* All monitor arms will have some wobble if you draw on the pen display.
* The **Ergotron HX** has less wobble than the **Ergotron LX**, but still has some wobble.

## Reduce wobble

The way I reduce wobble when drawing with monitor arms, regardless of brand, is simple.

First, I lower the monitor arm as close to the desktop as possible.

If the bottom edge makes contact with the desktop, that alone helps stabilize the display and reduce some wobble.

Sometimes it is not possible to make the bottom edge of the tablet touch the desktop. Or the contact is not stable enough. When this happens, I roll up a towel and place it under the bottom edge. This provides more contact and stability.

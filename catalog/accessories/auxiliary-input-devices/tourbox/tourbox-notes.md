# TourBox notes

## Summary

I have been using a TourBox regularly since July 2021. It has become a required piece of equipment in my digital art workflow. I have multiple drawing workstations, and each one has its own TourBox device attached.

## Adjustment time

I originally purchased the TourBox NEO in November 2020. I used it for about a month and then stopped. It was very difficult for me to remember to use the device. I often fell back to my normal keyboard shortcuts. After a few weeks, I put it back in its box and left it there untouched for about four months.

After a particularly frustrating drawing session where I had to rely heavily on keyboard shortcuts, I committed to retraining myself to use the TourBox. I brought it out of storage and made a concerted effort to make it part of my workflow.

* I forced myself to not touch the keyboard
* I read the user manual
* I learned how to customize it
* I tweaked the shortcuts in my drawing application to make it easier to use the TourBox for some tasks.

After about six months, my brain was fully trained to use the TourBox instead of relying on keyboard shortcuts. That investment of time was well worth it because it made me much more productive.

## What I like about the TourBox

**Productivity**

It has made me more productive simply by letting me stay in flow without looking at the keyboard or remembering an obscure shortcut.

**The TourBox Console app**

The accompanying TourBox Console application is very user-friendly. It is very easy to configure the device and create settings for specific applications.

A great feature of the application is its auto-switching option, which you can enable or disable. This is important because when you switch between windows, the TourBox uses the right configuration for that application. You do not have to switch profiles manually.

The software is also updated quite frequently.

**Connectivity**

The TourBox NEO supports only a wired USB connection.

The TourBox ULTRA supports both wired and Bluetooth connections. One downside for me is that it uses regular non-rechargeable batteries. It is a bit irritating to replace them every so often.

**Importing / Exporting configurations**

I have two machines, each with its own TourBox. One nice feature of the TourBox Console app is that it lets me export a configuration for a specific app and then import it on another machine.

## What could be better

I wish the dials and wheels had a little more resistance. I have one scroll wheel set to control brush size. Sometimes I accidentally brush against it, change my brush size, and do not notice until later. I do not use the large spinning dial at all. I originally set it to rotate the canvas, but I kept rotating the canvas by accident. So now I do not use that dial.

**Profile syncing**

It would be nice if the TourBox software could automatically sync all my TourBox devices so they share the same configuration without requiring export and import.

**Limitations with Microsoft store apps**

There is also an interesting limitation on Windows. It affects apps like Concepts, which are Microsoft Store apps rather than traditional Windows applications. Apparently, these applications are built differently, and the TourBox cannot assign a profile to them. Concepts is one example. I really enjoy sketching with it, but the TourBox cannot bind to it. That means I cannot have an application-specific configuration for it. I do not know whether this limitation comes from the TourBox software, Windows, or a combination of both.

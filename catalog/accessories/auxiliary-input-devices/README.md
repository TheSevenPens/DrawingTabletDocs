# Auxiliary input devices

## Overview

When using a drawing tablet, you often need to provide additional input to the computer. For example, you might press a shortcut key to change brushes.

Some tablets have built-in buttons and dials called [Auxiliary inputs](../../../core/expresskeys/) to perform that task. These express keys can be customized and can do different things in different applications.

But some tablets do not have express keys, and some people simply do not like using them, so they rely on other input devices.

## **Creative controllers**

This is a specialized category intended for creative work rather than gaming.

**TourBox**

The device I use is the TourBox Neo. It looks like a game controller, but it is really a fancy programmable keypad. More here: [TourBox](tourbox/)

**Clip Studio Tabmate**

The Clip Studio Tabmate is an interesting case. It is a controller built to work with a specific application: Clip Studio Paint. More here: [Clip Studio Tabmate](clip-studio-tabmate.md)

## Streaming keypads

These are aimed at streamers, but many people use them for other scenarios.

**ElGato Stream Deck**

The most popular one to look at here is the **ElGato Stream Deck**. It has programmable buttons - each with its own customizable LCD icon - that are grouped into profiles. And with its Smart Profiles feature it can switch to different profiles depending on which application you are using.

I used one of these for a couple of months with CSP, but I eventually stopped because the vast majority of what I needed was already covered by the TourBox.

**Loupedeck**

**Loupedeck** controllers could also be used. There are several models available, such as the Loupedeck Live and Loupedeck CT. I tried these in 2023, but I felt their software was very difficult to use.

## Tiny Keyboards

Keyboards are popular. Often, you will see someone using a much smaller keyboard than normal because it is easier to keep near the tablet, or it can be mounted to the pen display or an arm. More here: [Keyboards](../keyboards.md)

## MIDI devices

Some people use a MIDI device with some additional software to translate the MIDI data to keystrokes as another way to enter shortcut keys and use dials.

See this video for an example: ([https://youtu.be/TBF8NiWAue8](https://youtu.be/TBF8NiWAue8))

## Considerations

**App-specific profiles** - You will probably want an input device that can map its inputs differently for different apps. In other words, you set up one profile for Krita and another for Clip Studio Paint. The TourBox has this feature.

**Auto-switching profiles** - Ideally, the device should switch its profile depending on which app is on screen. This way, switching profiles does not require any change on the device. The TourBox has this feature.

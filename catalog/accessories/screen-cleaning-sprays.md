# Screen cleaning sprays

## Overview

There are specialized cleaning sprays for screens which work very well on pen displays.

More here: [Cleaning a drawing tablet](../../guides/maintain/cleaning-drawtabs.md)

## What I use

I've used two screen cleaning sprays: WOOSH and MISTIFY. Both work well.

I spray them into a microfiber towel that comes with the bottle. I want the cloth damp, not wet. Then I wipe down the tablet screen.

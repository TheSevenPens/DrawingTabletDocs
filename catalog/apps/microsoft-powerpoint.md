# Microsoft PowerPoint

## Tips

When you use a drawing tablet pen with Microsoft PowerPoint, it selects objects instead of drawing. You can make it enter "drawing" mode by default.

In **File → Options → Advanced → Pen**:

Uncheck **Use pen to select and interact with content by default**.

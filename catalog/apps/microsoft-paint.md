# Microsoft Paint

## Basics

* Microsoft Paint (aka MSPAINT) is one of the oldest Microsoft applications available on Microsoft Windows.
* [https://en.wikipedia.org/wiki/Microsoft\_Paint](https://en.wikipedia.org/wiki/Microsoft_Paint)

## Summary

It's still a relatively primitive application. Although some people do use it to create drawings or paintings, there are far better options. MSPAINT is still useful for quick image edits.

## Drawing tablet compatibility

MSPAINT also has two pressure-sensitive brushes. So it is useful for diagnosing pressure problems with a drawing tablet.

The two pressure-sensitive brushes are:

* Watercolor
* Oil

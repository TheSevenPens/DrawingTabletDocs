# TIP: Erasing with the pen eraser in Clip Studio Paint

## Overview

The steps below configure CSP to erase when you use the pen eraser. The active tool temporarily switches to the Eraser tool. When you switch back to the normal tip, CSP returns to the tool you used previously.

## Step 1: Configure the tablet driver's eraser action

* Open your tablet driver.
* Configure the eraser to use the **Erase** action.

## Step 2: Configure CSP modifier key settings

* Open Clip Studio Paint.
* Go to **File** > **Modifier Key Settings**. Your OS may show **Clip Studio Paint** > **Modifier Key Settings** instead.
* The **Modifier Key Settings** dialog opens.
* Select **General settings**.
* Select **Pen/Gesture**.
* Find the **Tail switch** setting.
* Change its assigned action to **Change tool temporarily**
* Another dialog will launch where you will need to pick an action.&#x20;
* Choose **Eraser**&#x20;
* Click **OK**.

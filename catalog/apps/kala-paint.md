# Kala Paint

{% hint style="warning" %}
Kala Paint is in **alpha** (version 0.1.34a as of November 2026). It is available to buy and has a free trial, but features are still being added and polished.
{% endhint %}

## Overview

Kala Paint is a desktop painting app made by Oliver Lawson, an illustrator, concept artist, and programmer in Cambridge, UK. It is published by Cooldog Studios Ltd. The product site says it will never add generative AI.

Product site: [https://kalapaint.app/](https://kalapaint.app/)

## Status and platforms

As listed on the product site in November 2026:

* **Windows** 10 and 11 - alpha, trial download available.
* **Linux** - alpha, trial download available as an AppImage for distros from 2022 or newer (Ubuntu 22.04, Fedora 35, Arch, etc.).
* **Android** and **iPad** - planned.
* macOS is not listed.

## Pricing

* $79.99 USD, one-time purchase. The site says it will never become subscription-based.
* A licence includes updates for the current major version and comes with 3 activations that can be moved between any mix of Windows and Linux machines.
* The free trial is fully featured for 14 days. After that, all features keep working and you can export JPG/PNG, but you can no longer save or load .psd or .wip files.

## Drawing tablet and pen support

The product site mentions pen pressure (for example, pressure controlling color or edge softness in the Lasso Paint tool) and a tablet pressure curve setting in the preferences. It does not mention tilt, and it does not name specific tablets, pens, drivers, or tablet APIs (such as Wintab or Windows Ink). Tablet and pen behavior has not been tested for this page yet.

## Features

Features the product site lists:

* GPU-based brush engine, with large brushes (the site shows 3000px) staying smooth; Photoshop ABR brush import is about 80% complete
* Lasso Paint tool with presets, textures, and pressure-controlled color or edge softness
* Color mixing that can sample all visible layers, plus an optional Hue Blending setting
* Non-destructive GPU filters (blur, sharpen, high pass, median, mosaic, textured blur, and more)
* Selective Colour+ recoloring, Liquify across multiple layers, and Mesh Warp
* Stored selections that can be reused across the layer stack
* Built-in timelapse recording
* Native .wip file format, plus PSD import and export
* Optional Sketchbook Mode for organizing paintings on a shelf
* Painting stats and a stroke heatmap, stored locally
* Customizable UI themes, remappable shortcuts, floating overlay controls, autosave, and crash recovery
* Per-layer symmetry, stabilisers (including pulled-string), layer groups, clipping masks, layer masks, blend modes, gradient maps, clone stamp, quickmask, a basic text tool, round canvases, and a greyscale proof view

# Ciallo

## Overview

Ciallo (pronounced "chow-lo") a vector paint program currently in development.

This is currently very actively in development. So it's not ready yet for a general audience. But it is a an interesting look at the future.

## My experience

I did try the development version on Steam in July 2026. So keep in mind I only exercised some features and did not have a long drawing session. Some quick things I noticed:

* Very fast and responsive.
* If you didn't know it was a vector app, you might not realize it from casual use. This is a compliment!&#x20;
* I was very happy with its vector erasing capabilities
  * The eraser produces good results compared to Clip Studio Paint's vector eraser which I am very used to.
  * The eraser shows a live preview of what it is going to erase before it does. This allows you to cancel a stroke before committing to it. I've never seen such a feature before in painting app.

Features I did not try (yet):

* Vector bucket fill
* Exploring the brush engine

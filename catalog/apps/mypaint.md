# MyPaint

* [https://mypaint.app/](https://mypaint.app/)
* [https://en.wikipedia.org/wiki/MyPaint](https://en.wikipedia.org/wiki/MyPaint)

**STATUS**: NOT ACTIVELY DEVELOPED

MyPaint has not been updated since 2020. The last release was v2.0.1 on 2020-05-29.

It seems to have been very popular with some artists, and the MyPaint brush engine has been imported into Krita.

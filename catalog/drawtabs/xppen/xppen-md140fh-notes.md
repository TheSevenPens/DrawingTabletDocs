# XP-Pen Artist Pro 14 GEN2 (MD140FH) notes

## Summary

I don't have hands-on experience with this tablet.

It is part of the same Artist Pro GEN2 series as the Artist Pro 16 GEN2 (MD160QH), which I have used, and I expect it to behave very similarly. More here: [XP-Pen Artist Pro 16 GEN2 (MD160QH) notes](xppen-md160qh-notes.md)

The main differences are size and resolution. This tablet has a 1920x1200 display, while the Artist Pro 16 GEN2 has 2560x1600.

## Basics

* Model number: MD140FH
* Released: 2023
* Product page: [https://www.xp-pen.com/product/artist-pro-14-gen-2.html](https://www.xp-pen.com/product/artist-pro-14-gen-2.html)
* Included pen: X3 Pro. More here: [XP-Pen X3 Pro pens](../../pens/xppen-pens/xppen-x3propen-notes.md)

## Specs

### Digitizer

* Technology: EMR
* Active area: 299 x 187 mm (11.8 x 7.4 in)
* Diagonal: 13.9"
* Pressure levels: 16384
* Tilt: ± 60°

### Display

* Native resolution: 1920x1200
* Panel: IPS
* Laminated: Yes
* Anti-glare: Etched glass

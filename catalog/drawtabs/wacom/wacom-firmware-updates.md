# Wacom firmware updates

You can update with the Wacom Center app.

If you are having problems with the Wacom Center on Windows, you can also try the Wacom Update Utility.

Here are the steps I got directly from Wacom:

* Open Wacom Center and leave it open.
* Click on the Windows icon (Start Menu).
* Select the Wacom Tablet folder.
* Click Wacom Update Utility.
* Back inside Wacom Center, click the setting icon (gear) in upper right.
* Go to Software Updates column and click Install update.
* Follow the instructions on screen to update firmware.

# Cintiq Pro 16 2016 (DTH-1620) notes

## Overview

This pen display was released in 2016. I've never tried it personally, but it did come with the Pro Pen 2 (KP-504E) so at least it has an excellent pen with industry leading pressure behavior.

The Cintiq Pro 32 is from the same generation: [Cintiq Pro 32 (DTH-3220) notes](wacom-dth3220-notes.md)

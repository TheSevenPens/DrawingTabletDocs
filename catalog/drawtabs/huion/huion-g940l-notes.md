# Huion Inspiroy Giano V2 (G940L) notes

{% hint style="info" %}
Everything below comes from Huion's published specs, not from hands-on testing.
{% endhint %}

## Overview

The Giano V2 (G940L) is the successor to the [Huion Inspiroy Giano (G930L)](huion-g930l-notes.md). It keeps the same large body and active area and upgrades the pen.

The pen is a significant upgrade based on my existing testing.

The tablet is arriving for me by the end of October 2026. When it shows up I will do a more thorough evaluation.

## Key changes from the G930L

It comes with the PW600 pen instead of the PW517 that came with the G930L.

Everything else - the active area, physical size, weight, 6 buttons, Bluetooth 5.0 and USB-C port are unchanged.

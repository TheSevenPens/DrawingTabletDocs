# Dial problems with the Huion GS1333 and GS1563

## Overview

Huion released to pen displays in 2025 with dials:

* Huion Kamvas 13 GEN3 - see [Huion Kamvas 13 GEN3 (GS1333) notes](huion-gs1333-notes.md)
* Huion Kamvas 16 GEN3 - see [Huion Kamvas 16 GEN3 (GS1536) notes](huion-gs1563-notes.md)

Soon after the release of these tablets, some users reports that the dials were having problems:

* Not working
* Partially working

## Prevalence

Based on other feedback, I do NOT think this is an issue that ALL GS1333 and GS1563 models have. But I do believe this issue is real and is definitely showing up with greater frequency than one would normally expect.

My experience: I have owned both these tablets and have NOT encountered any problems with the dials.

## Time until problem appears

The problem does not seem to appear the moment you start using the tablet, but a few months afterwards. This explains why reviewers may not have encountered this issue in their initial review.&#x20;

## Prevalence

**Dials** As of July 2026, that some people report that the dials have stopped working. I don't think this is a super common issue but it is an issue I see reported with a little more frequency than I would expect. I have not personally experienced any problems with the dials. Based on some user reports it does seem to be some physical issue with the dial.

## Cause

This is not a software or driver or operating system problem. It seems to be due to the a hardware issue with the dials.

## Potential fix

A reddit user disassembled his tablet and was able to fix the dials.&#x20;

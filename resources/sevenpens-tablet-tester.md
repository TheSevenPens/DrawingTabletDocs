# SevenPens Tablet Tester

## Overview

This is a simple web app that helps verify that your tablet and its core features work.

Try out the tester: [https://thesevenpens.github.io/WebTabletTesterBasic/](https://thesevenpens.github.io/WebTabletTesterBasic/)

User manual: [https://github.com/TheSevenPens/WebTabletTesterBasic/blob/main/USERMANUAL.md](https://github.com/TheSevenPens/WebTabletTesterBasic/blob/main/USERMANUAL.md)

Just open the tester and start drawing in the blue area.

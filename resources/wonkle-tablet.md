# Wonkle tablet

## Overview

This is an effort to make a Hall effect tablet for playing osu!.

This project by Pomp aims to productize two tablets. Both are optimized for gaming rather than drawing. The target game is osu!.

The first is a standard EMR tablet. Since it is designed for osu!, it will not include pressure support, because the game does not need it. It will likely omit tilt support as well.

The second tablet serves the same purpose, but it uses a very different technology. Rather than EMR, it uses Hall effect sensors.

This project used to be called `pompyboard`.

# SevenPens pen compatibility list

You can find pen compatibility information at the Drawing Tablet Data Explorer: [https://thesevenpens.github.io/DrawTabDataExplorer/](https://thesevenpens.github.io/DrawTabDataExplorer/)&#x20;



You can look up tablet models and find compatible pens. For example:&#x20;

* See **the compatible pens** tab for the Wacom Intuos Pro 2017 Medium PTH-660: [https://thesevenpens.github.io/DrawTabDataExplorer/entity/wacom.tablet.pth660](https://thesevenpens.github.io/DrawTabDataExplorer/entity/wacom.tablet.pth660)
* See the **compatible tablets** tab for the Wacom Pro Pen 2 KP-504E: [https://thesevenpens.github.io/DrawTabDataExplorer/entity/wacom.pen.kp504e](https://thesevenpens.github.io/DrawTabDataExplorer/entity/wacom.pen.kp504e)



Notes:

* This  Drawing Tablet Data Explorer has a lot of entries, but may be missing some pens and tablets
* Always verify compatibility with Wacom support before you purchase any pen.
* This data in the explorer is based on:
  * Kuuube's pen compatibility mastersheet
  * Wacom's published information
* Mistakes are possible in the data. If you see an error, please contact me!

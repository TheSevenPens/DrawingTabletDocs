# Beginner pen display recommendations

## Basics

* These are recommendations for pen displays, or screen tablets, that require a computer. If you want other kinds of tablets, see [Beginner drawing tablet recommendations](./).
* **Size.** A 13-inch display is a good way to get started with pen displays. I think 16-inch is the better long-term size.

## If I had to pick one

If I had to pick one pen display for a beginner, I would recommend the **Huion Kamvas 13 GEN3 (GS1333)**. [Huion Kamvas 13 GEN3 (GS1333) notes](../../../catalog/drawtabs/huion/huion-gs1333-notes.md)

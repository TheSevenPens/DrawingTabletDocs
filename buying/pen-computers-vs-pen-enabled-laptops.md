# Pen computers vs pen-enabled laptops

Pen computers and laptop computers can look exactly the same, use the same operating system, and even use the same pen technology (EMR). Here are two examples:

* Wacom MobileStudio Pro 16
  * Has a Screen
  * Runs Windows
  * Uses an intel CPU
  * Comes with a EMR pen
  * Can draw on the screen with pressure and tilt
* Samsung Galaxy Book 5 Pro 360
  * Has a Screen
  * Runs Windows
  * Uses an intel CPU
  * Comes with a EMR pen
  * Can draw on the screen with pressure and tilt

So it's natural to ask why I classify them differently:

* the MSP is a **Pen computer**
* the Book 5 Pro 360 as a **pen-enabled 2-in-1 laptop**

The reason is simple :

* The MSP is **intended and marketed to be used as a drawing tablet**. It's primary scenario and utility to its target customer involved using the pen to draw something. If the pen doesn't work - that's a MAJOR problem.
* The Book 5 Pro 360 is **intended and marketed to be used like a normal laptop** to do normal laptop tasks like browse the web, edit documents, check email, etc. The pen is useful but has somewhat secondary role. If the pen doesn't work, that is of course a problem or limitation but for many people the loss of the use of the pen does not prevent the user from using the device for its intended purpose.

## Pen tech

* All pen computers by my definiyion use drawing tablet pen tech - currently EMR
* Pen-enabled 2-in-1 laptops may use different technologies: EMR, AES, or MPP&#x20;

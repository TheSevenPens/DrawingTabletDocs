# Connecting a pen display to a USB-C port on a GPU

## Overview

It might be possible for you to use your USB C port on your GPU. But it also depends on what you're trying to accomplish.&#x20;

## Connecting for power, data, and video&#x20;

In this case the cable must provide video signal enough power and carry data. Currently I only know of one GPU that has a USB C port that&#x20;

might work for this case which is the NVIDIA RTX 2080 series. See this article: [https://www.eurogamer.net/digitalfoundry-2019-02-28-psa-the-usb-c-port-on-rtx-graphics-cards-isnt-just-for-vr](https://www.eurogamer.net/digitalfoundry-2019-02-28-psa-the-usb-c-port-on-rtx-graphics-cards-isnt-just-for-vr) ([archive](https://www.eurogamer.net/digitalfoundry-2019-02-28-psa-the-usb-c-port-on-rtx-graphics-cards-isnt-just-for-vr))&#x20;

To be clear I have never personally tested this scenario with a 2080 card.&#x20;

### Connecting for video only&#x20;

&#x20;If a USB C port is on a GPU it should definitely support a video signal.

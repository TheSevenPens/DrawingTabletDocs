# Using older tablet drivers

## Older tablets?

If you want to use older tablet drivers with an older drawing tablet, also see [Using older drawing tablets](../general/older-drawtabs.md). It covers many related topics.

## Finding older drivers

Manufacturers usually keep older driver versions on their websites. If you cannot find the driver you need, contact support. They can usually point you to it.

For Wacom, I keep a list here: [Older Wacom drivers](older-wacom-drivers.md)

## Challenges in using older drivers

You may run into problems using an older version of a tablet driver.

A common issue is that the operating system or app has changed since the driver was released. Some features may stop working. For example, a very new version of Photoshop combined with an older version of the Wacom driver can cause pen buttons to stop working. The exact issues depend on the operating system version, driver version, and app version.

## Alternatives to using older drivers

Consider [OpenTabletDriver](opentabletdriver/).

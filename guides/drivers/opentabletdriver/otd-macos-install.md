# Using OpenTabletDriver on MacOS

## Basic information

### Versions

Install version version 0.6.5 or later.

* Before version 0.6.5 - OTD does not support pressure and tilt on MacOS
* Version 0.6.5 or greater - OTD supports pressure and tilt on MacOS

### Processors

OTD runs on both Intel x86 and Apple silicon macs.

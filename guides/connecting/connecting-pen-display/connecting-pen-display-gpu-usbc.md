# Connecting a pen display to a USB-C port on a GPU

## Overview

It might be possible to use the USB-C port on your GPU. It depends on what you are trying to accomplish.

## Connecting for power, data, and video

In this case, the cable must carry video, power, and data. Currently, I only know of one GPU series with a USB-C port that might work for this case: the NVIDIA RTX 2080 series.

See this article: [https://www.eurogamer.net/digitalfoundry-2019-02-28-psa-the-usb-c-port-on-rtx-graphics-cards-isnt-just-for-vr](https://www.eurogamer.net/digitalfoundry-2019-02-28-psa-the-usb-c-port-on-rtx-graphics-cards-isnt-just-for-vr) ([archive](https://www.eurogamer.net/digitalfoundry-2019-02-28-psa-the-usb-c-port-on-rtx-graphics-cards-isnt-just-for-vr))

To be clear, I have never personally tested this scenario with an RTX 2080 card.

### Connecting for video only

If a USB-C port is on a GPU, it should support a video signal.

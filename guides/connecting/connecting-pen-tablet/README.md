# Connecting a pen tablet

## Overview

Most current pen tablets connect over USB. Some also connect wirelessly, usually over Bluetooth. See [Wireless connection](wireless-connection.md).

The original [Wacom Graphire Bluetooth (CTE-630BT)](https://101.wacom.com/productsupport/manual/BTManual.pdf) sends pen data over Bluetooth only. Its separate power jack is for the power adapter, not a USB data connection.

## Wired vs wireless

If your tablet supports wired USB, use the cable when setting it up for the first time.

In general, I recommend using the cable because any wireless connection typically has a little extra latency and is more prone to interference. Also in general, I've found wireless connection to sometimes just be a bit flakier and require manual reconnection sometimes. In general, I recommend using the cable. Wireless connections usually add a little latency, are more prone to interference, and can be less reliable.

## Basic cabling requirements

Pen tablets do not have a screen, so they do not draw much power or transmit much data. For a tablet that supports wired USB, a USB 2.0 cable that fits both ports and **carries data** is generally sufficient.

Check which connector your model uses. Many newer pen tablets have USB-C, but the [One by Wacom (CTL-472 and CTL-672)](https://www.wacom.com/en-gb/products/one-by-wacom) still uses Micro-USB on the tablet. Some older tablets have a permanently attached USB cable, such as the Wacom Intuos 4 XL.

If you want to use 3rd-party cables, see [Using 3rd-party cables with your drawing tablet](../3rd-party-cables-for-drawtab/).

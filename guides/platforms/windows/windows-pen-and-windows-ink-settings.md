# Windows Pen & Windows Ink settings

## Launching Pen & Windows ink settings

There are several ways to get to these settings

### Method 1: Use the Run Command (Fastest method)

1. Press `Win + R` .
2. Type `ms-settings:pen` and press **Enter**.

### Method 2: Go to Windows **Settings** then navigate down

* Windows 11&#x20;
  * Press `Win + I` to open settings
  * Click on **Bluetooth & devices**&#x20;
  * Scroll down to find **Pen & Windows Ink**
  * Expand **Additional Pen settings**&#x20;
  *
* Windows 10:
  * Press `Win + I` to open settings
  * Click on **Devices**&#x20;
  * Scroll down to find **Pen & Windows Ink**
  * Expand **Additional Pen settings**&#x20;

# Windows Tablet PC settings

## Launching Tablet PC Settings

### Method 1: Use the command line (fastest)

* Press `Win + R`.
* Type `control.exe /name Microsoft.TabletPC` and press Enter.

### Method 2: Use the Control Panel

* Launch the Control Panel
* Search for "Tablet PC Settings"

# Dead pixels

## Frequency of occurrence

A dead pixel does occur on a small percentage of monitors and pen displays.

I have not seen it be very common on pen displays from any manufacturer, and none of my pen displays from Wacom, Huion, or XP-Pen have any dead pixels.

## Fixing

It _might_ be possible to fix a dead pixel.

See this video: [https://www.youtube.com/watch?v=5pvtiV3B\_nE](https://www.youtube.com/watch?v=5pvtiV3B_nE)

## Returning your tablet or getting a refund

Usually a single dead pixel will not be enough to qualify for a return or refund.

If you have a lot of them or a cluster of them, then you have a case for a refund.

In either case, there is no harm in checking to see if you can return the product.

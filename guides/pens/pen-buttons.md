# Pen buttons

## Number of buttons

* The vast majority of drawing tablet pens have two buttons.
* Some consumer Wacom models have only a single button.
* A few pens have three buttons, for example, a Wacom Pro Pen 3.

## Default button actions

These are the default settings for Wacom pens with two buttons.

* **lower button** (the one closer to the nib) - set to perform a **mouse right-click**
* **upper button** (the one farther from the nib) - set to perform a **mouse left double-click**

## Customizing button actions

The actions taken by the buttons can be customized, usually to perform a mouse action, a keypress, a system action, or nothing.

## Common button customizations

Other things people configure their buttons to do:

* **MOUSE DOUBLE CLICK** - because some apps use a double-click
* **CTRL-Z** keypress - to perform undo
* **SPACE** keypress - in many apps, `Space` + dragging the pen will pan the drawing canvas
* **CTRL+SPACE** keypress - in many apps, this will zoom in and out of the canvas (Krita, Photoshop, Illustrator)
* **NO ACTION** - sometimes people accidentally press the buttons too often, so they set the button to do nothing
